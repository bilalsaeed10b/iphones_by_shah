# iPhones by Shah — Website build brief

Exported: 11 October 2026 at 20:20 (Asia/Karachi)
Decisions recorded: 81/95. Unselected recommendations are not approved choices.

## Core scope
- Home with the supplied logo and the three supplied phone models; iPhone 18 Pro Max at the center and iPhone 16 Pro Max as a supporting phone.
- Current stock as the primary CTA and a prominent homepage section.
- Individual device pages with condition /10, actual media and clear device disclosures.
- Prepared WhatsApp enquiries carry the stock ID, model and advertised price; staff confirms availability.
- Phone request workflow with preferences, contact details and staff follow-up.
- Protected admin for inventory, requests, image / video uploads, availability and team permissions.
- Responsive layouts, poster fallbacks, reduced motion, search indexing, share previews and handover.

## Suggested delivery sequence
Confirm brief → design and 3D optimization → stock / device / requests → protected admin / database / media → real content → QA / staff training → launch / handover.

## Suggested implementation plan
- Public catalogue: published database-backed inventory only; private costs, complete identifiers and customer information never appear in public responses.
- Protected admin: server-checked authentication and role permissions; device entry, inspection, media, pricing, availability, requests and recoverable archives.
- Stock unit: ID, model, storage, color, selling price, condition /10, battery source, PTA and carrier status, disclosures, publication / availability states; private purchase cost and identifiers are restricted.
- Media: linked to the individual stock unit; validate file type / size, optimize images and videos, select cover and order, provide alt text and object storage.
- Requests: model / budget / preferences, consent, private contact details, status, assigned staff, follow-up and a public request reference.
- Optional commerce: atomic availability checks / reservation locks, expiry, cancellation, payment failure, delivery and refunds only when selected.
- 3D and performance: immediate poster, optimized lazy-loaded models, bounded rendering cost, motion paused off screen, reduced motion, mobile fallback; indexable pages and share previews.
- Real store data requires durable server storage. This planning page saves decisions in the browser only.
